## Review workflow

1. Run pwsh ./bin/review-customizations.ps1 after adding or changing a customization.
2. Review every item under **Placement flags** against [the placement rules](./instructions/customization-placement.instructions.md).
3. Record deliberate placement decisions in [customization-scope.json](./customization-scope.json).
4. Run pwsh ./bin/review-customizations.ps1 -Check before committing.
